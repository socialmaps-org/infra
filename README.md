# socialmaps.org Infrastructure

* [direnv](https://direnv.net/) for autoloading environment variables containing secrets and more.
* [secretive](https://secretive.dev/) for protecting SSH keys on macOS.
* [Hetzner](https://www.hetzner.com/) for renting infrastructure.
* [OpenTofu](https://opentofu.org/) for managing infrastructure, and [TFLint](https://github.com/terraform-linters/tflint) for linting OpenTofu files.
* [Ansible](https://docs.ansible.com/) for configuring hosts, and [Ansible Lint](https://ansible.readthedocs.io/projects/lint/) for linting Ansible files.
